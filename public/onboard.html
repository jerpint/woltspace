🦫 woltspace

get set up in a few steps

01 environment pending
Fill in your secrets at ~/wolts/.env:
CLAUDE_CODE_OAUTH_TOKEN — from claude.ai/settings → API keys
HUMAN_NAME — your name
Then restart: woltspace stop && woltspace start
02 claude code auth pending
Your CLAUDE_CODE_OAUTH_TOKEN authenticates Claude Code inside the container.
Get it from claude.ai/settings → API keys and add it to your .env.
Token is injected at container start — a restart is needed after updating .env.
03 language model optional
Needed for the Telegram / Slack bot to reply. Add one to .env:
ANTHROPIC_API_KEY — console.anthropic.com
OPENROUTER_API_KEY — openrouter.ai/keys
The bot uses claude-haiku-4-5 by default (fast & cheap).
04 telegram optional
Chat with your wolt on Telegram:
TELEGRAM_BOT_TOKEN — from @BotFather on Telegram
ENABLE_TELEGRAM_BOT — set to true
Then run /telegram in the terminal to finish bot setup.
05 meet your wolt last
Once Claude Code is authenticated, run /create-wolt in the terminal.
Your wolt introduces itself, asks who you are, and starts building its space.
On first boot this runs automatically — check the terminal (left pane).
