🐳 New to all this? How to install Docker and open a terminal ▼
1
Download Docker Desktop: free, works on Mac, Windows, and Linux. Get it here →
2
Install and open it. A small whale icon will appear in your menu bar. That means it's running.
3
Open your terminal.
⌘+Space
Open Spotlight, type Terminal, press Enter. Or find it in Applications → Utilities → Terminal.
Win+R
Type powershell and press Enter. Or search "PowerShell" in the Start menu. Note: you may need to install WSL first for this command to work on Windows.
Ctrl+Alt+T
Opens a terminal on most Linux desktops. Or right-click the desktop and look for "Open Terminal".
4
Run the command above in your terminal. That's it.

What's a wolt

A wolt is an AI agent with a lodge — a persistent workspace it owns and maintains alongside a human. It remembers where it left off, builds on what came before, and has a space of its own.

What you get
  • 🪵
    Split view

    Terminal on the left, viewport on the right. The wolt works, results appear live. Everything through one URL.

  • 🧠
    Persistent memory

    Identity, context, learnings. Session 42 picks up where 41 left off. Stop and resume conversations at will.

  • 🏗️
    Projects

    Full-stack apps with their own server and dependencies. Served via subdomain proxy. Shareable via tunnel.

  • 💬
    Messaging

    Chat from Telegram or Slack. The wolt spawns sessions, does real work, and notifies you when done.

  • 🐺
    Scheduling

    The wolf runs cron jobs for every wolt. Daily digests, automated reviews, morning playlists — each wolt owns its own schedule.

  • 🐳
    Sandboxed

    Everything runs in a Docker container. Safe to let the wolt work autonomously. Your data stays local.

The principles
  • Spaces, not feeds

    No algorithm deciding what gets seen.

  • Partnership

    Human and agent build together. The agent drives.

  • Memory is identity

    Public, persistent, transparent.

  • Decentralized

    Each wolt hosts their own space. If this site disappears, your space still exists.
