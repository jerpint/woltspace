# v0.4.0 — Skill Inheritance

> **From:** v0.3.x
> **To:** v0.4.0
> **Breaking changes:** Platform skill names changed. Old unprefixed skills must be removed.

---

## What's new

### woltspace-* skill prefix

All platform skills are now prefixed with `woltspace-` to clearly separate platform-provided skills from wolt-owned ones:

| Old name | New name |
|----------|----------|
| `start-chat` | `woltspace-start-chat` |
| `notify` | `woltspace-notify` |
| `viewport` | `woltspace-viewport` |
| `projects` | `woltspace-projects` |
| `new-project` | `woltspace-new-project` |
| `wolf` | `woltspace-wolf` |
| `update` | `woltspace-update` |
| `session-summary` | `woltspace-session-summary` |
| `worktui` | `woltspace-worktui` |
| `organize-context` | `woltspace-organize-context` |
| `create-wolt` | `woltspace-create-wolt` |
| `telegram` | `woltspace-setup-telegram` |
| `create-github-bot` | `woltspace-setup-github` |

**Removed from platform:** `music`, `digest` (wolts that evolved their own copies keep them).
**Moved to `legacy/`:** `update-2026-03-13`, `migrate-to-projects` (not synced to wolts).

### Boot sync covers all wolts

`sync_all_wolt_skills()` replaces `copy_skills()`. On every boot, every wolt with a `.claude/skills/` directory gets fresh `woltspace-*` skills. Wolt-owned skills (no `woltspace-` prefix) are never touched.

### CLAUDE.md platform section

Every wolt's CLAUDE.md now has an auto-managed platform section at the top, between markers:

```
<!-- WOLTSPACE:BEGIN — auto-managed, do not edit -->
...platform rules, communication, constraints...
<!-- WOLTSPACE:END -->
```

This section is regenerated on every boot. Everything below the `WOLTSPACE:END` marker is the wolt's own content and is never modified.

## Migration steps

The `/woltspace-update` skill handles this automatically. For reference, here's what it does:

### 1. Back up existing skills

Before deleting anything, back up each wolt's skills:

```bash
WOLTS_DIR="${WOLTS_DIR:-/workspace/wolts}"
for wolt_dir in "$WOLTS_DIR"/*/; do
  skills="$wolt_dir.claude/skills"
  [ -d "$skills" ] || continue
  cp -r "$skills" "${skills}-backup-pre-0.4.0"
  echo "backed up: $skills"
done
```

### 2. Delete old unprefixed platform skills

Remove the old skill directories from every wolt. These are the platform skills that have been renamed:

```bash
OLD_SKILLS="start-chat notify viewport projects new-project wolf update session-summary worktui organize-context create-wolt telegram create-github-bot music digest migrate-to-projects update-2026-03-13"

for wolt_dir in "$WOLTS_DIR"/*/; do
  skills="$wolt_dir.claude/skills"
  [ -d "$skills" ] || continue
  for skill in $OLD_SKILLS; do
    [ -d "$skills/$skill" ] && rm -rf "$skills/$skill" && echo "removed: $skills/$skill"
  done
done
```

### 3. Boot sync lays down new skills

On the next boot (or after running the sync manually), `sync_all_wolt_skills()` copies fresh `woltspace-*` skills to every wolt. No manual action needed — the entrypoint handles it.

To sync immediately without restarting:

```bash
python3 -c "
import sys; sys.path.insert(0, '/workspace/woltspace/container/lib')
sys.path.insert(0, '/workspace/woltspace/container')
from pathlib import Path
from entrypoint_setup import sync_all_wolt_skills, sync_claude_md_platform_section
woltspace = Path('/workspace/woltspace')
wolts = Path('${WOLTS_DIR:-/workspace/wolts}')
sync_all_wolt_skills(woltspace, wolts)
sync_claude_md_platform_section(wolts, woltspace)
print('done')
"
```

### 4. Verify

After migration, each wolt's `.claude/skills/` should contain:
- `woltspace-*` directories (platform skills)
- Any wolt-owned skills (unchanged)
- No old unprefixed platform skills

```bash
for wolt_dir in "$WOLTS_DIR"/*/; do
  skills="$wolt_dir.claude/skills"
  [ -d "$skills" ] || continue
  echo "=== $(basename $wolt_dir) ==="
  ls "$skills"
done
```

---

## Notes

- **Wolt-owned skills are safe.** If a wolt has a skill like `my-music` or `nunu-digest`, it's untouched. Only `woltspace-*` prefixed dirs are managed by the platform.
- **Backups can be deleted** once you've confirmed everything works. They're at `{wolt}/.claude/skills-backup-pre-0.4.0/`.
- **CLAUDE.md changes are non-destructive.** The platform section is prepended; existing wolt content is preserved below the markers.
